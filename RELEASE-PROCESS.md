# Выпуск Creative Relab

Версия берётся из AssemblyInfo.cs PC Care/PC Guard и optimizerDuck.csproj PC Tune; для PC Record — native/Program.cs. Папка сборки — builds/<slug>-<version> рядом с репозиторием. Артефакты — releases, только на D.

1. Доработать исходники, поднять версию, обновить README/журнал изменений
2. Выполнить подходящие проверки без изменений основной защиты; для драйвера использовать только отдельный стенд. Хостовый сценарий не вызывает установщик драйвера
3. Собрать updates/Build-Updates.ps1 и проверить интерфейс/реальную загрузку; helper входит во все три пакета
4. Собрать приложения, обновить настоящие скриншоты и сводки verification
5. tools/Build-PortableReleases.py создаёт ZIP и соответствующие исходники, включая исходники общего helper. portable/Build-Portable.ps1 создаёт и проверяет EXE-распаковщики
6. Зафиксировать исходники в Git, создать отдельные теги pc-care-vX.Y.Z / pc-guard-vX.Y.Z / pc-tune-vX.Y.Z. Приложить ZIP, EXE, source.zip и SHA256SUMS. Прежние выпуски не перезаписывать
7. Сверить digest и размер всех GitHub assets, скачать пакет обратно и проверить SHA-256
8. Обновить локальные папки D:\PC Care, D:\PC Guard, D:\PC Tune через модуль распаковщика: сохранить Data и резервировать старые файлы. Работающую программу сначала закрывает её владелец
9. Обновить site/releases.json настоящими URL GitHub. Каталог программ размещается только в /software/, бинарные файлы остаются на GitHub. Существующие tools, art и 1111 не менять
10. Проверить опубликованный каталог, версии, ссылки, галереи и сохранить реальные результаты. Отдельно указывать, какие испытания относятся к прежнему бинарнику

Авторизация публикации и обновления локальных программ дана владельцем проекта. Пароли, токены, Data, приватные профили и образы VM в Git и релизы не включаются.

Для PC Record сборка выполняется apps/pc-record/Build.ps1; зависимости фиксируются Dependencies.json и восстанавливаются Restore-Dependencies.ps1. tools/Build-PCRecordRelease.py использует явный список файлов, не включает Data/Recordings и добавляет к source ZIP соответствующие исходники FFmpeg. Весь цикл сначала проверяется на копиях на D. Необязательные физические проверки отмечаются отдельно от автоматических тестов.
