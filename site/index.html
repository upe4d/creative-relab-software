Распаковка вместо установки

Все выпуски на GitHub ↗
01

Выберите формат

ZIP для ручной распаковки или EXE-распаковщик с выбором папки на диске D.

02

Запустите из папки

Регистрация в системе не нужна. Для отдельных системных действий приложение может запросить права администратора.

03

Сохраните свои данные

Настройки находятся в папке Data рядом с приложением. Перед обновлением закройте программу; распаковщик сохраняет существующую Data.

Нужно ставить .NET и другие компоненты?

PC Tune поставляется со средой выполнения. PC Care и PC Guard используют встроенный в поддерживаемые Windows .NET Framework. Подробности совместимости есть в README каждого выпуска.

Будут отключены Defender или IObit?

Распаковщики их не переключают. Программы не применяют оптимизации автоматически: системные действия выбираются отдельно.

Как узнавать о новых версиях?

Страница запрашивает публичный список GitHub Releases. Если GitHub недоступен, показывает сохранённые сведения с явной отметкой.
