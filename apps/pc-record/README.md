# PC Record 1.0.0

Бесплатная переносимая программа записи экрана от Creative Relab, @creativerelab.

## Запуск

Распакуйте portable ZIP в отдельную папку на D и запустите PC Record.exe.
Либо используйте EXE-распаковщик: он предлагает D, проверяет архив и сохраняет Data.
Записи находятся в Recordings, настройки и временные файлы в Data рядом с программой.
Никакой регистрации приложения, автозапуска или установки драйверов нет.
IObit, Defender и системные политики программа не переключает.

Требования: Windows 10 22H2 / Windows 11 x64, .NET Framework 4.8,
Microsoft Edge WebView2 Runtime, Visual C++ Redistributable x64, Media Foundation.
Компоненты должны уже присутствовать: автоматической установки нет.
В редакциях N/KN необходим Media Feature Pack. Для работы интерфейса Интернет не нужен;
проверка обновлений и открытие сайта используют Интернет.
Текущие испытания выполнены на Windows build 26200.9711; это не проверка всех версий Windows.

## Возможности

- Запись монитора, выбранной области, отдельного окна или камеры
- Системный звук и микрофон с отдельными устройствами и громкостью
- Камера поверх экрана, окна или области
- H.264 в MP4 и MKV, режимы 30/60 FPS, исходный размер, 720p или 1080p
- Пауза и продолжение, остановка с сохранением, отсчёт 0/3/5 секунд с отменой
- Плавающая панель поверх окон: таймер, пауза, стоп и возврат к программе
- Ctrl+F9 для запуска/остановки, с сообщением о занятом сочетании
- Курсор, подсветка кликов и системная рамка захвата
- Снимки PNG и редактор: стрелка, рамка, текст, отмена и сохранение отдельной копии
- Библиотека с поиском, фильтром типа, сортировкой и страницами по 50 файлов
- Обрезка MP4/MKV в отдельный MP4 без изменения оригинала
- Две темы и сохранение параметров; микрофон и камера при каждом запуске выключены
- Проверка новых выпусков на GitHub и загрузка распаковщика с проверкой SHA-256

Предпросмотр — одиночный настоящий снимок при выборе источника.
Внешние файлы пока не импортируются. Библиотека показывает до 1000 файлов;
длительность автоматически читается для 12 последних видео при обновлении списка.
Неизмеренные длительности не являются нулевой длиной записи.

## Границы и сохранность

Минимум перед стартом — 256 МиБ свободного места на D.
Показания проверяются раз в две секунды; при остатке менее 64 МиБ запись
останавливается с сохранением. Это не гарантия сохранности при отключении питания,
аварии Windows, внезапном отказе накопителя или недоступности исходного устройства.
Закрытие окна источника останавливает и сохраняет текущую запись.
MP4 записывается фрагментами с заголовком в начале. При уведомлении Windows
о приостановке или разрыве таймера более 30 секунд приложение пытается завершить
запись с предупреждением. Повторный старт выполняется вручную. Настройки сна
не меняются; при аварии сохранность последнего фрагмента не гарантируется.

Двухчасовая проверка прервалась при переходе компьютера в сон с причиной
Thermal Zone. Она не засчитана. Повторный длительный тест отложен владельцем;
результаты коротких проверок приведены в отчёте. Проверка речи микрофона отложена.

Рамка, захват курсора и исключение плавающей панели зависят от API Windows
и приложения-источника. Защищённые DRM-окна могут не захватываться.
Указанные FPS — режим выходного файла, не обещание уникальных кадров на слабом ПК.
Аппаратный кодировщик, расписание, стриминг и многодорожечный монтаж не входят в 1.0.
Подписи Authenticode у исполняемых файлов пока нет.

Программа не удаляет пользовательские файлы автоматически. После MKV/обрезки
в Data/Temp могут оставаться промежуточные материалы; это осознанно сохранённые файлы.
Не удаляйте их во время записи или обработки.

## Исходники и сборка

В исходном комплекте откройте apps/pc-record на диске D.
Выполните Restore-Dependencies.ps1, затем Build.ps1.
NuGet и FFmpeg скачиваются с фиксированными версиями и проверкой SHA-256.
Сборка использует csc.exe из .NET Framework Windows и исходники ../../updates.
Код захвата — ScreenRecorderLib, кодирование записи — Media Foundation,
обработка — отдельные FFmpeg 8.1.2 LGPL и OpenH264. Лицензии находятся в licenses и tools.
Соответствующие исходники FFmpeg и сценарии сборки приложены к source ZIP.

--verify-capture: базовая проверка искусственного окна и обработки
--verify-release: отсчёт, 60 FPS, размеры, ограничения и безопасные остановки
--verify-controls: автоматическая проверка собственного интерфейса
--verify-gallery: настоящие снимки собственного интерфейса
--verify-extended: проверка устройств и длительная запись; запускает камеру/микрофон
только при явном запуске этого испытательного режима.

Для чтения собственных файлов используется штатный PowerShell ReadMedia.ps1,
ограниченный каталогами Recordings, Data/Preview, Data/Temp. Настройки защиты,
ACL и ExecutionPolicy не изменяются. Временный HTTP-канал обработки привязан
к 127.0.0.1 и одноразовому случайному адресу одного файла.
