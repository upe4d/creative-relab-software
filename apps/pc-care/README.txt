PC Care 1.2.0
Creative Relab | @creativerelab
https://tools.crrl.ru/software/#pc-care

Бесплатное портативное приложение для Windows 10 / 11.

ЗАПУСК
Открой D:\PC Care\PC Care.exe. Установка и подключение к интернету
не требуются. Используется уже установленный .NET Framework 4.8.
Приложение не добавляет себя в автозагрузку и не устанавливает службу.


ВЕРХНЯЯ ПОЛОСА ОКНА
Заголовок и кнопки окна оформляет PC Care. Их цвет следует выбранной
теме приложения независимо от цвета стандартного заголовка Windows.
Перетаскивание, изменение размера и кнопки управления сохранены.

ТАБЛИЦЫ И ФИЛЬТРЫ
Нажатие на заголовок столбца сортирует таблицу; повторное нажатие
меняет направление. Стрелка рядом с заголовком показывает порядок.
Размеры сравниваются по байтам, даты — по времени, а не по тексту.
Выбранная сортировка сохраняется при обновлении результатов.

Поиск есть в таблицах дисков, категорий, файлов, автозагрузки и истории.
Несколько слов ищутся одновременно. Для списков файлов доступны
пороги размера, для автозагрузки — фильтр статуса. Фильтры сочетаются;
счётчик показывает число видимых и общее число результатов.

Фильтр не снимает отметки с выбранных файлов. В сумме очистки отдельно
указано число отмеченных файлов вне текущего списка. Перед удалением
подтверждается полный выбранный набор.

Автозагрузка: красные строки — запуск разрешён, зелёные — выключено
Windows или PC Care; нейтральные — статус не удалось определить.
Статус Windows StartupApproved читается без изменения. Это состояние
конфигурации автозапуска, а не наблюдение за фактическим запуском процесса.

ОБЗОР
Показывает фактическую загрузку CPU, используемую физическую память
и свободное место на локальных фиксированных дисках. Обновление —
каждые 2 секунды. CPU появляется после двух измерений.

ОЧИСТКА
1. Нажми «Проверить файлы».
2. Выбери категорию: внизу появятся полные пути найденных файлов.
3. Категории и отдельные файлы можно отмечать независимо.
4. Нажми «Очистить выбранное» и подтверди удаление.

По умолчанию проверяются файлы старше 7 дней в пользовательском TEMP,
Windows\Temp и Cache/Code Cache/GPUCache профилей Edge и Chrome.
Кэш работающего браузера пропускается. Cookies, сохранённые пароли,
история браузера и личные документы не входят в правила очистки.
Ссылки и junction не обходятся. Занятые или изменившиеся после проверки
файлы пропускаются; причины доступны в журнале.

Корзина по умолчанию не выбрана. Её содержимое открывается отдельной
кнопкой; полная очистка корзины всех дисков требует дополнительного
подтверждения. Временные файлы удаляются напрямую, минуя корзину.
Откат удаления файлов и очистки корзины не предусмотрен.

При достижении ограничения по количеству файлов/элементов или времени
показывается сообщение о частичных результатах. Уже найденные файлы
можно просмотреть и выбрать. Кнопка «Отменить» прекращает дальнейшую
обработку; уже выполненные удаления остаются в журнале.

АВТОЗАГРУЗКА
Отображаются значения HKCU/HKLM Software\Microsoft\Windows\CurrentVersion\Run
(HKLM: оба разрядных представления) и файлы пользовательской/общей
папки Startup. Таблица учитывает отметки Windows StartupApproved.
Политики и другие механизмы Windows могут дополнительно влиять на запуск.
Для статуса, который прочитать не удалось, используется «Не определён».

При выключении исходная запись сначала сохраняется в Data\state.json;
файл из Startup копируется в Data\StartupBackups и проверяется по SHA-256.
Восстановление доступно через тот же раздел или «История» и сохраняет
точный исходный текст/тип значения. Существующее другое значение
или файл не перезаписываются. Записи всех пользователей могут требовать
прав администратора; при нехватке прав операция завершится с ошибкой.
Службы, планировщик задач и StartupApproved не изменяются.

КРУПНЫЕ ФАЙЛЫ
Укажи папку или корень диска и нажми «Найти файлы».
По умолчанию показываются файлы от 500 МиБ, до 1000 крупнейших результатов.
Кнопка «Показать в Проводнике» выделяет выбранный файл. Удаления в этом
разделе нет. Ссылки, $RECYCLE.BIN и System Volume Information пропускаются.

ДАННЫЕ И НАСТРОЙКИ
Всё хранится рядом с EXE в Data на диске D:
  settings.json       — пороги, пределы проверки, выбранная тема
  state.json          — журнал и резервные записи автозагрузки
  StartupBackups\     — сохранённые файлы автозагрузки
  errors.log          — диагностика ошибок, если они возникли
  *.bak              — предыдущие сохранённые версии JSON

Настройки редактируются при закрытом приложении. Поддерживаются:
  MinimumAgeDays          1–365, по умолчанию 7
  ScanFileLimit           100–1000000, по умолчанию 100000
  ScanEntryLimit          не меньше ScanFileLimit, до 5000000
  ScanTimeLimitSeconds    10–3600, по умолчанию 600
  LargeFileMinimumMB      1–1000000, по умолчанию 500 (МиБ)
  LargeFileResultLimit    10–10000, по умолчанию 1000
  Theme                  Dark или Light

После изменения настроек запусти приложение заново.
При переносе программы сохраняй папку Data: она нужна для отката.
Одновременно разрешён один экземпляр из одной папки.

СБОРКА ИЗ ИСХОДНИКОВ
В Windows PowerShell:
  powershell -NoProfile -ExecutionPolicy Bypass -File "D:\PC Care\Source\Build.ps1"
Используется системный csc.exe, C# 5 / .NET Framework 4.8, WPF.
Сборка: /warn:4 /warnaserror+ /optimize+ /platform:anycpu.
Пакеты NuGet и отдельный SDK не нужны.

ПРОВЕРКИ
  "D:\PC Care\PC Care.exe" --self-test
Изолированные тесты создают свои файлы в Data\SelfTests и временный
ключ HKCU\Software\PCCare\Tests. Проверяются удаление, пропуски,
границы путей, junction, отмена, резервирование, откат и коллизии.
Реальная автозагрузка и корзина не изменяются.
Результаты: Data\self-test-latest.txt.

  "D:\PC Care\PC Care.exe" --ui-smoke
Проверка пяти экранов и выбора файлов на тестовых данных.
Окно вне видимой области; отчёт и снимки — в Data\UiSmoke.

  powershell -NoProfile -ExecutionPolicy Bypass -File "D:\PC Care\Source\Verify.ps1"
Проверка фактических TEMP/кэшей, списка автозагрузки и мониторинга
только на чтение. Ничего не очищает и не выключает.
Отчёт: Data\Verification\read-only-results.json.

ТЕХНИЧЕСКИЕ ГРАНИЦЫ ВЕРСИИ 1.1
Это самостоятельная реализация согласованных пяти разделов.
В состав не входят алгоритмы IObit, очистка реестра, антивирус,
обновление драйверов, дефрагментация и автоматическое расписание.
Исполняемый файл не подписан цифровым сертификатом.
Если операция не выполнена, интерфейс показывает ошибку, а не успех.

ОБНОВЛЕНИЯ 1.2.0
В разделе «Наши программы» кнопка «Проверить обновления» открывает центр Creative Relab.
Он показывает текущую версию и последнюю стабильную на GitHub, скачивает распаковщик
