# PC Tune 1.0.2

Русская переносимая производная optimizerDuck 2.29.0. Исходный репозиторий: https://github.com/itsfatduck/optimizerDuck. Точный исходный commit указан в UPSTREAM.txt. Автор оригинала fatDuck (itsfatduck); права и лицензии сохранены. Изменённая версия распространяется по GPLv3 вместе с исходниками.

## Запуск

Откройте D:\PC Tune\PC Tune.exe. Устанавливать .NET или зависимости не нужно: среда выполнения входит в папку. Для применения системных настроек Windows запрашивает права администратора. Само открытие программы оптимизации не применяет.

Папку нужно переносить целиком. Настройки, журнал, история изменений, данные отката и временные файлы хранятся в Data рядом с EXE. Не удаляйте Data, если нужен откат. Папка сборки и инструменты разработки также размещены на D. Устанавливать драйверы для PC Tune не требуется.

## Возможности

42 оптимизации из базового проекта: производительность, конфиденциальность, видеокарта, питание, службы, интерфейс и компоненты AI. Есть управление автозагрузкой и задачами, очистка диска, настройки Windows, поиск и сортировка. Совместимость отдельных пунктов определяется текущей Windows и оборудованием. Названия и описания риска переведены на русский. Уровень риска не является гарантией ускорения или отсутствия побочных эффектов.

Откат использует сохранённое предыдущее состояние поддерживаемых операций. Удалённые временные файлы и удалённые приложения не восстанавливаются этой кнопкой. Сведения об изменённых, пропущенных, отказанных и необратимых шагах отображаются отдельно.

Центр безопасности Windows исключён из массовой настройки служб. IObit и Defender при разработке и проверке этой сборки не переключались. Не применяйте массовые настройки, не прочитав перечень действий в интерфейсе.

## Реклама

Нижний блок «Реклама · 18+» ведёт на https://zabivki.ru/. Это конструктор кальянных миксов: сочетания вкусов и пропорции. Изображение включено в приложение, запросов к сайту при открытии блока нет. Только нажатие запускает сайт в обычном браузере. Автоматическая проверка обновлений оригинального продукта отключена. Утилита и локальный рекламный блок работают без подключения, внешние ссылки требуют интернета.

## Проверки и ограничения

Build-PCTune.ps1 выполняет строгую Release-сборку, выбранные тесты локализации/сериализации и выпускает переносимую папку. Все остальные интеграционные тесты оригинала сохранены, но автоматически не выполняются: часть из них пишет в реестр или вызывает системные операции.

Режим: PC Tune.exe --pc-tune-verify. Он проверяет русские ресурсы, параметры форматирования, число оптимизаций и реальную навигацию WPF в двух темах при ширине 900 и 1350. Основной OperationRunner запрещает применение оптимизаций в этом режиме. Снимки и JSON находятся в Data\Verification. Режим изменяет только локальные настройки приложения, не применяет оптимизации Windows.

Проверки локализации, отрисовки и формата отката не подтверждают фактический эффект всех 42 оптимизаций или полный откат на разных версиях Windows. На основной Windows оптимизации при проверке не запускались. Результаты отдельных прогонов LTSC и границы аппаратной совместимости опубликованы в verification репозитория Creative Relab. Проверка всех пунктов на одном стенде не подтверждает работу на другом оборудовании.

## Повторная сборка

SDK получен по официальным метаданным Microsoft https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json с проверкой SHA512; информация в PC-Tune-toolchain\sdk-source.json.
