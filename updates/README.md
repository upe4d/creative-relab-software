# Creative Relab Updates

Вспомогательное переносимое окно для PC Care, PC Guard и PC Tune. Использует .NET Framework Windows, не добавляет службу, задачу или автозапуск. Доступно из раздела автора кнопкой «Проверить обновления».

Публичный GitHub Releases API выбирает последний подходящий выпуск по числовому номеру версии. PC Care использует стабильный канал, Guard и Tune видят также Preview. Требуются ровно один portable EXE, точный URL собственного репозитория, заявленные размер и digest SHA-256. Отсутствие готового файла или digest — ошибка, а не молчаливое переключение на старый выпуск.

Загрузка сохраняется в D:\Codex\downloads. Перед доступностью кнопки открытия сверяются размер и SHA-256. Повторное нажатие проверяет файл заново. Сам центр не закрывает приложение и не применяет обновление. Сначала закройте основную программу, затем откройте portable-распаковщик; он сохраняет Data и резервирует заменяемые файлы. Скачивание требует интернета; остальные функции приложений продолжают работать без сети. Ошибка сети не объявляется отсутствием новых версий. SHA-256 не является подписью издателя.

Сборка: Build-Updates.ps1, C# 5, Windows .NET Framework. Исходники разделены на сетевой клиент, окно и тесты. --self-test выполняет только изолированные фикстуры; --check и --download-check создают отчёт по указанному пути D и не запускают скачанный файл.

API: https://docs.github.com/en/rest/releases/assets
