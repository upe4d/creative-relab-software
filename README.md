# Creative Relab Software

Создатель семейства: **Creative Relab**, [@creativerelab](https://t.me/creativerelab).

Каталог: https://tools.crrl.ru/software/. Бинарные выпуски размещаются в GitHub Releases, сайт показывает последние версии и ссылки на GitHub.

| Программа | Задачи | Исходники |
|---|---|---|
| PC Care | Очистка, автозагрузка, крупные файлы, обзор ресурсов | apps/pc-care |
| PC Guard | Проверка файлов, карантин, сейф и инструменты безопасности | apps/pc-guard |
| PC Tune | 42 настройки Windows, задачи и данные отката | apps/pc-tune |

ZIP распаковывается вручную. EXE-распаковщик проверяет встроенный архив, предлагает папку на D, сохраняет Data и резервирует заменяемые файлы. Он не регистрирует приложение в системе. Для отдельных действий само приложение может запрашивать административные права.

PC Guard содержит экспериментальные модули. Распаковщик не устанавливает драйвер. Работа файлового наблюдателя не гарантирует остановку вредоносной программы до исполнения; производственная подпись драйвера отсутствует. Актуальные границы описаны в приложении и README.

PC Tune является производной optimizerDuck (fatDuck / itsfatduck). Точный upstream commit сохранён в apps/pc-tune/UPSTREAM.txt. Оригинальные авторы и GPLv3 сохранены. Возможность применить настройку зависит от Windows и оборудования; удалённые файлы не восстанавливаются кнопкой отката.

## Лицензии

Собственный код PC Care, PC Guard, каталога и распаковщика: MIT, см. файлы LICENSE.txt соответствующих каталогов. PC Tune: GPLv3, см. apps/pc-tune/LICENSE. Сторонние компоненты и наборы индикаторов имеют отдельные лицензии: в частности, в PC Guard сохранены MIT и GPLv3 для исходных IOC-наборов. Файлы лицензий и provenance находятся рядом с компонентами.

Каталог site использует Bootstrap с сохранённым MIT-заголовком. Рекламный блок Zabivki включает локальный логотип и открывает сайт только после нажатия. Без фоновых рекламных запросов.

## Структура

- apps: исходники трёх приложений.
- portable: общий распаковщик и его сценарий сборки.
- site: статический каталог с чтением GitHub Releases API и сохранённым резервным списком версий.
- verification: публичные сводки проверок без содержимого пользовательских файлов и настроек.

Локальные данные, секреты, образы VM и сборочные кэши в репозиторий не включаются.
## Аватар и скриншоты

В версиях PC Care 1.1.3, PC Guard 3.4.2 и PC Tune 1.0.2 используется предоставленный аватар Creative Relab. В каталоге у каждой программы отдельное описание и два настоящих скриншота. Кнопка увеличения открывает локальную галерею. [Проверки](verification/README.md).
